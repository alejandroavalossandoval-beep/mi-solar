# Mi Solar

App para iPhone (web instalable) que muestra los paneles solares en vivo usando la cuenta de Solar of Things:
flujo de energía, historial por día, mes y año, ahorro en pesos y avisos.

- Sin servidor: habla directo con la nube de Solar of Things desde el celular.
- El usuario y la clave se escriben en la app y quedan guardados solo en ese celular.
- Sin cuenta conectada muestra datos de ejemplo.

API no oficial, basada en cómo funciona la web de Solar of Things; puede cambiar sin aviso.
